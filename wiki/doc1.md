
# Doc1｜六大基酒風味圖譜

## 1. 主題介紹

基酒（Base Spirits）是許多經典調酒文化中的重要原料。不同基酒受到原料、發酵、蒸餾、熟成與產地等因素影響，形成各自的風味特色。

本篇從原料與風味特徵出發，整理六種常見基酒，建立基礎的風味分類概念。

## 2. 六大基酒的風味特徵

### Gin｜琴酒

- 主要特色：杜松子帶來的松木、草本與清新香氣。
- 其他風味：可能包含柑橘、花香及香料氣息。
- 風味關鍵：植物性香氣（Botanicals）。

### Brandy｜白蘭地

- 原料特色：常見以葡萄等水果發酵後的酒液為基礎。
- 風味特徵：可能呈現果香、熟成果乾及木質香氣。
- 風味關鍵：水果原料與熟成方式。

### Tequila｜龍舌蘭酒

- 原料特色：以藍色龍舌蘭為原料。
- 風味特徵：可能呈現植物性、草本、土壤與胡椒氣息。
- 風味關鍵：龍舌蘭品種、產地與製程。

### Vodka｜伏特加

- 原料特色：可使用不同含澱粉或糖分的農作物製作。
- 風味特徵：通常以相對中性、乾淨的風味印象為特色。
- 風味關鍵：原料、蒸餾與過濾方式。

### Whiskey｜威士忌

- 原料特色：以穀物為主要原料。
- 風味特徵：可能呈現穀物、香草、焦糖、木質及煙燻氣息。
- 風味關鍵：穀物種類、製程與熟成環境。

### Rum｜蘭姆酒

- 原料特色：與甘蔗及其加工產物有關。
- 風味特徵：可能呈現甘蔗、焦糖、熱帶水果及香料氣息。
- 風味關鍵：原料、發酵、蒸餾與熟成方式。

## 3. 風味比較

| 類型 | 主要風味線索 |
|---|---|
| Gin | 杜松子、草本、柑橘 |
| Brandy | 水果、果乾、木質 |
| Tequila | 植物性、草本、胡椒 |
| Vodka | 中性、乾淨 |
| Whiskey | 穀物、香草、木質 |
| Rum | 甘蔗、焦糖、熱帶水果 |

以上為常見風味描述，實際風味會因品牌、原料與製程而不同。

## 4. 核心知識整理

理解基酒風味時，可以從三個面向觀察：

1. **原料**：穀物、水果、甘蔗或植物性原料。
2. **製程**：發酵、蒸餾與過濾等製程差異。
3. **熟成**：木桶種類、熟成時間與環境可能帶來的變化。

這三個面向能幫助我們理解為什麼不同原料會形成不同的香氣與風味。

## 5. 延伸思考：非酒精飲品的風味應用

基酒風味分類也可以延伸到非酒精飲品設計：

- 草本與柑橘：可用於理解薄荷、迷迭香與檸檬的香氣搭配。
- 水果與木質：可研究果乾、茶與烘焙香氣之間的關係。
- 甘蔗與焦糖：可用於分析不同糖類帶來的香氣差異。

這些例子能協助我們將風味知識應用於日常飲品與感官設計。

## 6. 關鍵詞 Glossary

- Base Spirits：基酒
- Botanicals：植物性香料或香氣原料
- Distillation：蒸餾
- Fermentation：發酵
- Aging：熟成
