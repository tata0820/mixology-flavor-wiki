
# Mixology & Flavor Pairing
## 調酒風味學與經典結構

一個以風味科學、感官設計與飲品結構為核心的數位知識庫。

本專案整理飲品風味的組成、香氣來源、酸甜平衡、口感質地與視覺呈現，透過 Wiki 知識頁面與知識圖譜，建立彼此連結的學習系統。

> 從認識風味開始，理解一杯飲品如何形成完整的感官體驗。

---

## Project Goals｜專案目標

- 建立有系統的飲品風味知識庫
- 整理不同原料與風味之間的關係
- 建立 Wiki 頁面與知識圖譜
- 將知識庫轉化為可瀏覽的 HTML 教學簡報
- 透過 Loop / Graph 工作流程，記錄知識整理、檢查與修正過程

## Knowledge Topics｜知識主題

1. 六大基酒風味圖譜
2. 利口酒與加烈葡萄酒
3. 酸甜平衡與飲品結構
4. 糖漿種類與口感質地
5. 搖盪法與攪拌法的物理原理
6. 冰塊物理學與融水控制
7. 苦味與芳香分子的感官作用
8. 飲品器皿與裝飾物的設計功能

## Scope & Notes｜專案範圍

本知識庫以風味科學、感官設計與非酒精飲品的概念應用為主要學習方向。涉及酒精飲品的內容以文化、原料特性與概念知識為主，不提供酒精飲品調製配方或飲酒操作指引。

所有知識內容應標示來源，並區分已查證資訊與尚待查證的資料。
